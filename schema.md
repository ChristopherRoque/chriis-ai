# schema — chriis.ai

**N/A — no datastore.**

This project is a static HTML and CSS page served from a CDN. It has no
database, no API, no server-side code, no authentication, no cookies, and no
user input of any kind. Nothing is written anywhere.

The only data that leaves a visitor's browser is anonymous page-view telemetry
from Vercel Web Analytics, and only once Analytics is enabled in the Vercel
project dashboard. That data lives in Vercel, not in this repo, and there is no
schema here to own.

If this page ever gains a form, a click-tracking store, or any persisted state,
that change must land with a real schema in this file, in the same commit.

Foundation gate reference: `~/SecondBrain/feedback_foundation_gate_codebase_map_and_schema.md`
